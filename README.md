# Instagram Clone

A minimal cross-platform mobile app built with React Native and Expo that demonstrates a simple photo feed and the ability to create posts.

## Features
- Display a feed of posts with image, user, and caption.
- Add new posts through a simple form.

## Requirements
- Node.js and npm
- Expo CLI (`npm install -g expo-cli`)

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm start
   ```
   Use the Expo Go app on your device or an emulator to view the app.

## Testing
There are currently no automated tests. You can run the placeholder script with:
```bash
npm test
```
